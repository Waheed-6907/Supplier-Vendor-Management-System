**📦 Vendor–Supplier Management System**
**📖 Overview:**

The Vendor–Supplier Management System is designed to streamline product purchasing, order management, and payment handling between vendors and suppliers.
The system provides separate modules for Vendors, Suppliers, and Administrators, making business operations more organized and efficient.
This project demonstrates database integration, workflow management, and user interface design in a real-world business scenario.

**✨ Features:**

✔️ Vendor product browsing and order placement
✔️ Supplier order approval and status management
✔️ Vendor payment tracking
✔️ Admin portal for managing vendors and suppliers
✔️ Order status monitoring
✔️ Secure database storage for records

**🛠️ Technologies Used:**

💻 Java
🗄️ MySQL
🔗 JDBC Connectivity
🎨 Java Swing (UI)
🐙 GitHub for Version Control
📧 Jakarta Mail (Email Verification System)
📅 JCalendar (Date Selection UI Component)
🔐 jBCrypt (Password Hashing & Security)

**⚙️ System Modules:**

**🧑‍💼 Vendor Module:**
Browse available products
Place orders to suppliers
View order history
Manage payments

**🏭 Supplier Module**
View incoming orders
Approve or reject orders
Update order status
Track Earnings

**👨‍💻 Admin Module**
Manage vendors and suppliers
Monitor system operations
Maintain database records
